# Experimental Design

1. **Unified Detection Target:** Tar1–Tar5 perform IPM-based steganography on HEVC bitstreams. Cover and stego bitstreams are generated under consistent encoding conditions.

2. **Unified Data Sources:** All methods use the same `manifest.csv`. Zhao uses separately generated candidate IPM/SATD TXT files, while maintaining consistent `sample_id`, `split`, and `label` fields with the common data manifest.

3. **Consistent Data Partitioning:** Training, validation, and testing labels are imported from existing JSON files. No additional random splitting is performed, and test frames are strictly excluded from the training set.

4. **Method-Specific Syntax Features:** Each method retains its original feature representation: Cao (depth/IPM), Shen (PU), Zhao (candidate IPM/SATD), Dai-PU (PU maps), Cao-TU (CU/PU/TU), Zhai (motion vectors), Dai (prediction errors), and Cao264 (PEB transitions).

5. **Consistent Input Pipeline:** All methods extract information from customized HM decoder outputs containing actual syntax records, including `Frame` and `CTU Address`. Zhao additionally uses SATD information generated by a customized x265 encoder. Cross-domain methods retain their original feature representations rather than replacing them with IPM histograms.

6. **Standardized Outputs:** All methods generate `metrics.json` and `predictions.csv`. Traditional feature-based methods additionally export `features.csv`, while deep learning-based methods save training curves and model weights.
